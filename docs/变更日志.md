# 变更日志

本文件记录「风起时」社区平台的功能变更。按时间倒序排列。

---

## 2026-07-31：移动端体验与内容规则调整

### 移动端导航与心情页布局

- **移动端底部导航新增「风屋」入口**：底部导航栏由两项（心情/广场）扩展为三项（心情/风屋/广场），与桌面端标签页保持一致。
- **心情页两卡并排同高**：「最近心情」与「今日心情记录」改为同一行同一高度展示（`items-stretch` + 固定 `h-[160px]`），移动端窄屏下自适应缩放，不再换行堆叠。
- **今日心情记录器移动端紧凑化**：心情按钮、字号、间距在移动端缩小（`h-8 w-8`），`sm:` 断点恢复原尺寸，避免小屏溢出。
- **风广场标签匹配用户主页**：桌面端「风广场」标签在 `/users/*` 路径下保持高亮，导航状态更符合直觉。
- **用户主页返回按钮**：用户主页新增返回按钮（`BackButton`），移动端浏览体验更顺畅。

### 内容规则调整

- **放宽帖子/评论长度限制**：标题、正文、评论的最小/最大长度限制大幅放宽（标题最小 1 字、正文最大 100000 字、评论最大 20000 字），去掉原有过紧的硬编码上限（标题 500 字、正文 100000 字、评论 20000 字被错误收紧为 100/500/50000/2000 等），恢复为以内容长度下限校验为主。
- **发帖标题可选**：简易模式下发帖不再强制要求标题，正文首行自动兜底为标题。

### 简易模式帖子（isSimpleMode）

- **新增 `Post.isSimpleMode` 字段**：发帖时可选择「简易模式」，帖子在信息流中直接渲染正文内容（而非仅标题 + 摘要 + 「全文」链接），标题显示「简」徽标。
- **简易模式图片上传重构**：图片 URL 从 draft 的 `simpleImages` 数组单独管理，不再通过正则从 Markdown 内容中提取，删除图片更可靠。
- 数据流打通：`schema → draft → 提交请求 → 创建服务 → 信息流展示` 全链路支持 `isSimpleMode`。

### 评论图片上传

- **评论表单支持直接添加图片**：评论框底部新增图片按钮，支持多选图片上传至 `comments` 目录，上传后以缩略图形式预览，可单独移除；提交时自动拼接为 Markdown 图片语法。
- **评论表单简化**：以原生 `textarea` 取代重型 `AddonEditor`，移除快捷键提示（Ctrl+Enter 仍可用）。

### 移除友情链接功能

- **整体下线友情链接模块**：删除 `FriendLink` 数据模型、`FriendLinkStatus` 枚举、申请/审核 API、`/link` 页面、侧栏友情链接区块、后台友情链接管理表单与设置项。
- **清理关联代码**：移除插件系统的 `friend-links.*` 插槽与 surface、`friend-links` 上传目录、内容安全 `friendLink.name` 场景、后台仪表盘待审核计数、附件引用追踪中的友情链接 LOGO 引用。
- **清理自助广告残留引用**：附件引用状态追踪中移除 `SelfServeAdOrder`（自助广告）查询。

### 用户主页雷达图心情维度

- **雷达图「魅力」维度替换为「心情」维度**：基于近 30 天心情记录计算心情均分（五档心情映射 1-5 分），未记录时显示「暂无心情记录」。
- 相关查询由同步改为异步（`buildUserProfileRadarData` 返回 Promise）。

### 杂项

- **`.gitignore` 补充**：忽略 `*.log`、`dev-error.txt`、`dev-output.txt`、`*.tar.gz`、`.omo/` 等运行日志与本地产物。
- **测试同步**：移除友链申请、自助广告相关断言，与代码删除保持一致。
